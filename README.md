# 🌟 Responsive Profile Card Website

A modern and responsive personal profile card built using **HTML, CSS, and JavaScript** with interactive animations, dark mode, typing effects, glassmorphism UI, and responsive design.

---

## 🚀 Features

* 🎨 Modern Glassmorphism UI
* 🌙 Dark Mode Toggle
* ✨ Animated Gradient Background
* ⌨️ Typing Text Animation
* 📱 Fully Responsive Design
* 🖼️ Interactive Profile Image Zoom
* 🔗 Social Media Links
* 📋 Copy Email to Clipboard
* 👋 Dynamic Greeting Based on Time
* 🧠 Skill Tags with Hover Effects
* ⚡ Smooth Hover Animations
* 💎 Professional Portfolio Design

---
